# Intern Engineering Foundation

## Day 2 – Git & Version Control

This project is created as part of the Software Engineering Intern Bootcamp.

The purpose of this project is to practice basic Git and GitHub workflow, including:

- Repository management
- Feature branches
- Commits
- Push and pull
- Pull Requests
- Code review
- Documentation
